                      📊 股票智能分析系统 - 使用说明
================================================================================

一、系统要求
--------------------------------------------------------------------------------
- Windows 10/11 或 macOS 或 Linux
- Python 3.8 或更高版本
- 网络连接（用于获取股票数据）

二、快速开始
--------------------------------------------------------------------------------

Windows 用户：
1. 双击运行 "启动.bat"
2. 等待依赖安装（首次运行）
3. 打开浏览器访问：http://localhost:3000

macOS / Linux 用户：
1. 打开终端，进入本文件夹
2. 运行：chmod +x 启动.sh （仅首次）
3. 运行：./启动.sh
4. 打开浏览器访问：http://localhost:3000

三、功能介绍
--------------------------------------------------------------------------------
✅ 实时股票数据 - 支持所有A股股票
✅ K线图分析 - MA5/MA10/MA20均线
✅ MACD/RSI指标 - 技术分析工具
✅ 支撑位/压力位分析 - 带理由说明
✅ 缺口分析 - 识别跳空缺口
✅ 智能预测 - 未来3天价格预测
✅ AI辅助决策 - 结合基本面和技术面
✅ 模拟持仓 - 记录您的买入点
✅ 财经新闻 - 实时市场资讯

四、常见问题
--------------------------------------------------------------------------------

Q: 首次运行很慢？
A: 首次需要安装依赖包，后续会快很多。

Q: 无法获取股票数据？
A: 请检查网络连接，确保能访问外网。

Q: 如何停止服务？
A: 在终端窗口按 Ctrl+C 即可。

Q: 数据保存在哪里？
A: 持仓数据保存在浏览器本地存储中。

五、技术支持
--------------------------------------------------------------------------------
如有问题，请检查：
1. Python 版本是否正确
2. 网络连接是否正常
3. 端口3000是否被占用
